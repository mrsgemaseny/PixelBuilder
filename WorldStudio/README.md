# MiniLife World Studio

Единый инструмент авторства глобальной карты MiniLife. Источник правды - один файл `world.json`.
Старые карты PixelBuilder читаются и пишутся обратно, пока ты от них не откажешься.

## Сборка и запуск (Windows)

```
cd C:\Users\murat\IdeaProjects\new_world\PixelBuilder\WorldStudio
build.cmd test          rem сборка + 893 проверки + проверка совместимости со старым PixelBuilder
bin\WorldStudio.exe
```

Для проверки совместимости нужен собранный старый редактор: один раз `..\build.cmd`.
Ничего ставить не нужно: компилятор `csc` из .NET Framework 4.5+, как у PixelBuilder.

## Мир - один файл `WorldStudio\world.json`

`bin\WorldStudio.exe` при запуске сразу открывает `world.json` из корня WorldStudio. Выбирать и собирать ничего не нужно.
Файл уже собран из трёх основных карт (`data\sources.json`, файлы MiniLife только читаются):
- политика - `MiniLife\future\map\Политическая карта с фракциями и зданиями.json`;
- ландшафт - `MiniLife\future\map\nature.json`;
- дикие земли - `MiniLife\future\map\Д=деревни(пока что просто метки), г-имперские армии.json`.

Если `world.json` удалить, при следующем запуске он сам соберётся из этих карт заново и сохранится.
Все правки (реестр, отношения, маршруты, заметки) - в этом же файле, Ctrl+S. Копии версий - `world.history` рядом (в git не идут).

## Редактор

Сверху: имя мира и состояние (сохранён / не сохранён), слой, инструменты, отмена, проверка, меню "...", "Сохранить".
Слева: видимость и замок слоёв, палитра со счётчиком клеток у каждого значения. Справа: клетка или находки.
Подсказка с клавишей - при наведении на любую кнопку. Сообщения - короткие всплывашки над картой, окна - только для вопросов.

| Действие | Как |
|---|---|
| Слой | сегмент сверху: Ландшафт / Политика / Дикие земли / Объекты (клавиши 1-4); глаз и замок - слева |
| Инструменты | Кисть B, Прямоугольник R, Заливка F, Пипетка I, Ластик E, Маршрут армии M, сетка G |
| Значение | палитра слева; число справа - сколько клеток или объектов уже с этим значением |
| Карта | колесо - масштаб, правая или средняя кнопка - сдвиг; внизу справа - минус, процент, плюс, вписать (Ctrl+0) |
| Отмена | Ctrl+Z / Ctrl+Y, до 500 шагов; подсказка на кнопке говорит, что именно отменится |
| Клетка | клик - справа координаты, тайлы, ландшафт, владелец, объект, армия, заметка (сохраняется при выходе из поля) |
| Маршрут армии | M, армия в списке слева, клики по клеткам, Backspace - убрать точку, Enter - сохранить, Esc - сбросить |
| Проверка | F5 или кнопка сверху; клик по находке подсвечивает клетки, Esc - назад к клетке |
| Реестр | Ctrl+R: список слева, карточка справа; правка применяется при выходе из поля, удаление спрашивает |
| Отношения | Ctrl+T: матрица кружков (цвет - знак, размер - сила, в углу - ответ), ползунок или число внизу, стрелки двигают выбор |
| История | меню "..." - История версий: копия перед каждой перезаписью, откат с подтверждением |
| Экспорт | меню "..." - Экспорт в PixelBuilder: три файла как сейчас; старый PixelBuilder их открывает |
| Оформление | меню "..." - Оформление: как в Windows (по умолчанию), светлое, тёмное |

Автосохранение раз в 5 минут пишет `<имя>.autosave.json` рядом с миром, основной файл не трогает.
Копии версий: папка `<имя>.history` рядом с миром, сами не удаляются.
Журнал ошибок: меню "..." - Папка журнала ошибок.

## Что игра читает

`world.json`, схема 1. Ключи отсортированы, одинаковые данные дают одинаковые байты (удобно в git).
Ссылки только по id (`state.reinhard`, `wild.group_1`, `army.east`, `obj.city_3`); цвета - только в реестре и легенде.
`generator_version` зарезервировано за игрой и не меняется инструментом.
Объекты `village_mark` - независимые поселения без лорда (метка Д), `army_mark` - имперские армии (метка Г);
в PixelBuilder это "Независимое поселение" (`independent_settlement`) и "Имперская армия" (`imperial_army`).
Старые файлы, где Д записано деревней, а Г - городом, читаются так же.

## Структура

```
WorldStudio/
  src/Core/Domain         модели и правила, без UI и файлов
  src/Core/Serialization  JSON, world.json, pixel_architect_v1, xlsx, импорт и экспорт старых карт
  src/Core/Validation     14 проверок раздела 8, по классу на проверку
  src/Core/Application    команды undo/redo, документ, версии, журнал ошибок
  src/UI                  WinForms, без бизнес-логики
  data/                   шаблон мира (реестр, легенда, отношения), таблица поселений автора, основные карты (sources.json)
  tests/                  тесты, проверка совместимости, проба интерфейса, фикстуры
  docs/                   REPORT_*, DECISIONS, OPEN_ITEMS, OBSERVATIONS
```
