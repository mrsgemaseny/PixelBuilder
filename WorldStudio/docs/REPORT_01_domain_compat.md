Дата: 2026-11-18. Репозиторий игры и файлы PixelBuilder не менялись (PixelBuilder только читался и собирался во временной папке для проверки совместимости).

## 1. Что сделано

1. Домен по разделу 7: сетка (21 x 15, 63 чанка, последний 8 тайлов), координаты, стабильные id с запретом повторной выдачи, государства, дикие земли, армии (origin и position допускают пустое значение), объекты с 8 типами, матрица отношений, корень World.
2. Свой JSON (D-04): порядок ключей, исходный текст чисел, повтор ключа как ошибка, позиция ошибки (строка и столбец), ограничение глубины.
3. Кодек pixel_architect_v1: чтение без потерь (все поля, неизвестные поля и слои на прежних местах, исходные ключи клеток, порядок клеток), строгая проверка до применения, запись в стиле PixelBuilder (CRLF, отступ 2).
4. Атомарная запись текстовых файлов (временный файл и замена), UTF-8 без BOM.
5. Тесты: 365 проверок, 0 провалов. Проверка совместимости через настоящий старый PixelBuilder: 35 из 35.
6. Найден и исправлен дефект до сдачи: писатель добавлял пустое "layers" в файлы старого формата, и PixelBuilder переставал их открывать (D-11).

## 3. Как проверить

На Windows, из `PixelBuilder\WorldStudio\`:
1. Если `..\bin\PixelBuilder.exe` ещё не собран: `..\build.cmd`.
2. `build.cmd test`.
3. Ожидается: `BUILD OK`, затем `passed=365 failed=0 skipped=0`, `WORLDSTUDIO_TESTS_PASS`, затем 35 строк `OK ...`, `files=35 failed=0`, `COMPAT_PASS`.

## 6. Риски и наблюдения

- [WARNING] Сборка проверена только mono. Windows csc C# 5 может отличаться в мелочах (mono шире принимает некоторые конструкции). Первый запуск `build.cmd test` у тебя закрывает этот риск.
- [WARNING] Записанный файл отличается от исходника байтами: CRLF везде, `map_size` в одну строку, пустые объекты как `{}`. Смысл, порядок и состав полей те же; старый PixelBuilder даёт тот же экспорт. Байт-в-байт для pixel_architect_v1 не требуется (D-09).
- [INFO] Совместимость с PixelBuilder проверена для прочитанных и перезаписанных файлов. Для файлов, которые WorldStudio создаст с нуля из world.json, её проверит Этап 2: экспорт пойдёт через тот же CompatProbe.
- [INFO] В модели World пока нет чтения и записи world.json, это Этап 5. Кодек пишет только pixel_architect_v1.
