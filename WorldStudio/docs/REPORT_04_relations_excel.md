# REPORT_04 - Редактор отношений и Excel (Этап 4)

## 1. Что сделано
Импорт и экспорт .xlsx без NuGet (zip + SpreadsheetML, защита от XXE). Импорт ищет таблицу по названиям государств в любом месте первого листа, принимает sharedStrings и inline-строки, другой порядок строк и столбцов, регистр, "ё", прочерк на диагонали; диапазон не обрезает (это проверка 8). Окно отношений: N x N, подсветка от красного к зелёному, в ячейке "значение (обратное)", строка "туда и обратно" снизу, правки - командами с отменой, ввод вне -100..100 не принимается.

## 2. Новые файлы
`src/Core/Serialization/Xlsx/XlsxRelationsCodec.cs`, `src/UI/RelationsForm.cs`, `tests/fixtures/relations_author_like.xlsx` (сделан openpyxl: заголовок, таблица со смещением, верхний регистр, другой порядок, дробные числа).

## 3. Как проверить
Ctrl+T - Экспорт в Excel - открыть в Excel. Импорт из Excel - матрица совпадает с Приложением B.

## 4. Тесты
S4.XlsxRoundTrip, S4.XlsxAuthorLike, S4.XlsxBroken - пройдено; openpyxl читает экспорт (XLSX_OPENPYXL_PASS).
