# REPORT_05 - Единый экспорт и резервные копии (Этап 5)

## 1. Что сделано
world.json: детерминированная запись (D-21), строгое чтение с путём поля и строкой ошибки, миграции схемы на дереве JSON, перенос generator_version, lore, buildings и неизвестных полей без изменений, retired_ids (удалённый id не выдаётся после перезагрузки). Версии: копия перед перезаписью, журнал с sha256, откат с копией текущего, автосохранение в отдельный файл (D-22). Сохранение в UI - в фоне (Prepare / Write / Commit).

## 2. Новые файлы
`Serialization/WorldJson/WorldJsonCodec.cs`, `WorldMigrations.cs`, `Serialization/Json/JsonRead.cs`, `Application/VersionStore.cs`, `Application/WorldDocument.cs`, `Application/ErrorLog.cs`, `src/UI/Dialogs.Import.cs` (HistoryForm).
