# REPORT_06 - Редактор карты и интерфейс (Этап 6, добавлен в REPORT_00)

## 1. Что сделано
M1: слои Ландшафт / Политика / Дикие земли / Объекты с видимостью и замком; кисть, прямоугольник, заливка, пипетка, ластик; мазок - один шаг истории; undo/redo 500 шагов; инспектор клетки с заметкой. M2: реестр государств, групп и армий. Маршрут армии ломаной по клеткам. Панель проверки. Импорт трёх карт с явной семантикой, экспорт в PixelBuilder, история версий, автосохранение 5 минут. Все правки - команды (WorldEdits), в UI нет бизнес-логики. Ошибки - короткое сообщение, подробности в журнал.

## 2. Новые файлы
`src/UI/Program.cs`, `MainForm.cs`, `MapCanvas.cs`, `RegistryForm.cs`, `RelationsForm.cs`, `Dialogs.Import.cs`, `Strings.cs` (все строки интерфейса), `Theme.cs`, `AssemblyInfo.cs`; `src/Core/Application/Commands.cs`, `WorldEdits.cs`; `tests/UiProbe.cs`.

## 3. Как проверить (чек-лист для Windows)
1. `build.cmd test`, затем `bin\WorldStudio.exe`.
2. Новый мир из трёх карт; карта совпадает с твоей политической картой при выключенном ландшафте.
3. Кисть по ландшафту, Ctrl+Z - откат одним шагом. Замок на слое - правка не проходит, внизу причина.
4. Слой Объекты - поставить замок, поставить поверх город (замена), отменить.
5. Маршрут: M, армия, клики, Enter; F5 - разрывы маршрута видны в проверке 11.
6. Реестр: цвет государства - карта перекрашена; удалить государство с клетками - отказ с причиной.
7. Сохранить, закрыть с правками - вопрос "сохранить?".

## 4. Тесты
App.PaintUndo, App.FillAndLayers, App.HistoryDepth (250 шагов отмены), App.Objects, App.Registry, App.ArmyRoute - пройдено. UiProbe под Xvfb: окно с миром, мазок кистью через события мыши (4 клетки, один шаг), блокировка слоя, объект кистью, отмена; скриншоты всех окон - UI_PROBE_PASS.
